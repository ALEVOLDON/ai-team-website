# 🌐 AI-Team Studio — Официальный сайт-презентация и голосовой Devlog

Эта папка (`website/`) содержит **полностью автономный сайт-витрину** для демонстрации **AI-Team Studio**, публикации голосовых/текстовых обзоров и истории версий **без раскрытия закрытого исходного кода студии**.

## ✨ Как работает авто-обновление?

1. **При выходе новой версии студии:**
   * Вы как обычно обновляете версию в [`pyproject.toml`](../pyproject.toml) и добавляете описание релиза в [`CHANGELOG.md`](../CHANGELOG.md).
   * Скрипт [`sync_website.py`](../sync_website.py) (вручную через `update_website.bat` или автоматически через Git-хук `pre-commit`) считывает новую версию, парсит все пункты релиза, пересчитывает количество тестов и генерирует новый пост в дневнике разработки и на таймлайне версий!

2. **Как добавить свой голосовой обзор:**
   * **Способ 1 (Прямо на сайте):** Нажмите кнопку **`🎙️ Добавить обзор`** в правом верхнем углу сайта, запишите голос с микрофона и скачайте готовый аудиофайл в папку `website/audio/`.
   * **Способ 2 (Привязка к версии):** Положите файл `v0.13.0.mp3` (или `.wav`) в папку `website/audio/` и запустите `python sync_website.py` — плеер этой версии автоматически подхватит вашу живую запись!
   * **Способ 3 (Свободный голосовой пост):** Положите любой аудиофайл (например, `news_october.mp3`) и по желанию текстовый файл `news_october.txt` в `website/audio/`, затем запустите `python sync_website.py` — на сайте появится новая карточка с вашей записью.
   * **Способ 4 (Авто-озвучка без микрофона):** Даже если вы не записали аудиофайл, встроенный на сайте плеер умеет сам озвучивать текст любого релиза голосом прямо в браузере по нажатию кнопки `▶`!

## 🚀 Как выложить на GitHub Pages / Vercel без кода студии?

Так как папка `website/` не содержит ни одной строчки Python-исходников вашей студии (только статический `index.html`, `styles.css`, `app.js` и публичные сводки в `data/site_data.js`), вы можете:
* Загрузить **только содержимое папки `website/`** в отдельный публичный репозиторий на GitHub и включить **GitHub Pages**,
* Или перетащить папку `website/` в **Netlify Drop / Vercel**.
